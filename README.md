# 汉画像·百戏乐舞：63 格实时互动乐队

这是一个可以直接运行、完全离线的浏览器互动装置。固定摄像头拍摄观众，程序把人物前景映射到 9×7 共 63 个格子；身体覆盖哪个格子，对应的汉代乐师、舞者或侍者就会从浅灰石刻状态“复活”，同时加入相应声部。

项目不依赖 TouchDesigner、云端接口、远程 CDN 或在线模型。视觉、音频、标定、触发、防抖、投影全屏均已包含。

## 一键运行

需要电脑已安装 Node.js 18 或更高版本。

- macOS：双击 `start.command`
- Windows：双击 `start.bat`
- Linux：运行 `./start.sh`
- 手动启动：在本目录执行 `node server.js`，打开 `http://localhost:4173`

摄像头权限只能在 `localhost` 或 HTTPS 安全环境使用，因此请在连接投影仪的本机打开 `http://localhost:4173`，不要直接双击 `index.html`。

## 真人交互的现场步骤

1. 打开作品，点击“进入作品”。
2. 点击右下角“控”，把“触发来源”切换到“摄像头”。
3. 点击“开启摄像头”。
4. 固定摄像头，确保画面里没有人，点击“采集空场背景”。程序会平均采集 18 帧。
5. 人进入画面后，身体与空场背景之间的差异会形成前景 Mask，并实时触发 63 个格子。
6. 打开“摄像头标定”，拖动四个红色角点，让网格覆盖真正的观众活动区域。
7. 点击“全屏投影”，按 `H` 隐藏全部控制界面。

光线、机位、焦距或摄像头镜像设置发生变化后，需要重新采集空场背景。

## 三个运行模式

- **自动演示**：无需摄像头，两个虚拟人物自动在画面中移动，适合验收和拍摄演示。
- **鼠标 / 触摸**：按住并拖动画面，相当于移动一名观众；支持多点触摸。
- **摄像头**：固定机位背景差分，支持多人同时进入；人静止后仍会保持触发，不是只检测运动。

## 快捷键

| 键位 | 功能 |
|---|---|
| `H` | 隐藏 / 显示界面 |
| `D` | 打开 / 关闭摄像头标定 |
| `F` | 进入 / 退出全屏 |
| `M` | 静音 / 恢复声音 |
| `A` | 6.5 秒唤醒全部 63 个格子 |
| `空格` | 暂停 / 继续自动演示 |

## 触发算法

浏览器以 192×108 的低分辨率读取摄像头：

1. 采集固定机位的空场 RGB 背景；
2. 每帧计算色彩差异与亮度差异；
3. 通过 3×3 邻域去噪和膨胀，得到稳定人物前景；
4. 计算前景与 63 个透视格子的覆盖率；
5. 使用不同的开启 / 关闭阈值、连续帧确认和慢速淡出，避免边缘闪烁；
6. 所有声部从同一时刻循环播放，格子只控制声部音量，因此观众随时加入都不会打乱节拍。

选择背景差分而不是浏览器内下载 AI 模型，是为了让交付包真正离线、免安装、无模型许可证依赖，并适合固定摄像头的展览环境。摄像头位置不固定、背景频繁移动或需要户外使用时，再替换为 YOLO 人体分割即可，渲染和 63 格逻辑无需改动。

## 现场建议参数

- 输出：1920×1080，横屏，Chrome 或 Edge 最新稳定版。
- 摄像头：1080p、30fps；固定在三脚架或建筑结构上，关闭自动跟踪。
- 观众区：尽量避免窗外强光、频闪灯和会自己运动的大屏背景。
- 默认前景灵敏度：54；格子开启：7%；关闭：3%。
- 误触较多：提高“前景灵敏度”数值或提高格子开启阈值。
- 人体缺失：降低“前景灵敏度”数值或降低格子开启阈值。

## 素材说明

- 画像石底图和八类人物均为本项目重新生成的原创视觉素材，没有直接提取参考作品画面。
- WAV 声部由项目脚本程序化合成，不含第三方录音采样。
- `assets/source-highres/` 保留了完整高分辨率 PNG，运行时使用的是裁切压缩后的版本。
