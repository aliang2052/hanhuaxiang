# 交付报告：汉画像·百戏乐舞 1.0.0

## 已实现

- 9×7 共 63 个独立触发格。
- 自动演示、鼠标/多点触摸、真人摄像头三种输入。
- 固定摄像头空场采集、RGB 前景差分、形态学去噪。
- 四角透视标定，可把 63 格映射到楼梯、走廊或任意观众区。
- 开启/关闭双阈值、连续帧确认、缓慢淡出，避免格子抖动。
- 63 个浅灰“未激活人物”和深色“复活人物”。

- 8 类人物透明素材、1 张底图、9 条同步循环音轨。
- Web Audio 分组混音、全局静音、同步启动。
- 全屏投影、界面隐藏、现场快捷键和移动端基本适配。
- Node 零依赖本地服务器，无远程请求。
- 自动化 smoke test、预览截图和状态测试接口。

## 运行边界

当前真人分割使用固定机位的空场背景差分，而不是 YOLO。它在室内展览、楼梯、走廊等背景稳定的场景中可以真实完成多人触发，而且完全离线。摄像头移动、背景持续变化或室外光照剧烈变化时，需要重新采集空场，或把输入层替换成人体分割模型。
