# 汉画像·百戏乐舞 V2 实现与验收记录

版本：`3.0.0-v2`  
基线：`c8fdfec9e2a470dc7adee6251a05a0d1afd45933`

## 本轮实现

### 视觉与构图

- 保留 63 个实际非均匀建筑画格、左右纹样带、上下云气神兽纹样和中央纵向台阁。
- 主场景从 8 个独立人物重复铺陈改为 47 个不同运行时构图；63 个节点由 46 个单人、4 个双人、10 个三人和 3 个中央大型群像构成。
- 狭窄画格使用更大的单人乐师；壁画派生人物采用 cover-fit 裁去部分建筑边缘；中央画格使用独立的大尺寸群像矩形。
- 背景由浅灰改为暖棕/铜色画像石质感，提高梁柱、画格、人物和边框的层次。

### 动画与颜色特效

- 视觉动画接入音频共享传输时钟，不再使用与音频无关的独立页面时间。
- 按弹拨、吹奏、拉弦、击鼓、击钟、拍板、铙钹、舞蹈、百戏、仪仗等类别设置动作节奏。
- 敲击类动作使用清晰 attack，持续类动作保留呼吸/摇曳，动作有 attack / release 形态。
- 每个类型配置乐器附近的局部效果锚点。激活时只在人物、乐器和附近区域显示金、朱、青、蓝、紫矿物色，以及敲击环、放射线、舞袖粒子和墨线轨迹；不做整屏变色。

### 声音系统

- 由 8 个演奏声部增加到 18 个独立演奏声部，并保留 1 条厅堂环境声，共 19 条。
- 所有 WAV 为 44.1 kHz、32 秒、同步循环；19 个文件哈希均不同。
- 声部包括琴、横笛、琵琶、编钟、弓弦、鼍鼓、袖舞、仪礼、笙、排箫、瑟、拍板、铙钹、节铃、扁鼓、石磬、建鼓和角。
- 多声部共用四秒乐句和细分节拍，浏览器使用统一起点启动；按真实画格位置计算左右声像和覆盖力度。
- 新增确定性双声道厅堂脉冲响应、湿声发送、早期反射和动态压缩，降低多格同时触发时的削波风险。
- 参考混音诊断：32 秒，峰值约 `-6.83 dBFS`，RMS 约 `-21.00 dBFS`，包含持续谐波、全频打击瞬态和动态留白。

## 保留能力

- 完全离线运行，无运行时外部请求。
- 实体摄像头 MediaPipe 人像分割、模拟摄像头、人物轮廓主画面投影。
- 人物覆盖到哪个实际建筑画格，就触发该画格的视觉、动作和声部。
- 鼠标精准模式一次只命中一个真实画格；多点触摸保持多区域触发。
- Homography 标定、摄像头持续重连、异步代次清理、响应式和 4K 像素上限保持不变。

## 明确限制

- 现有 24 个壁画派生素材来自同一项目壁画源，部分仍保留画像石建筑或题饰线条；V2 通过放大和裁切减弱了“矩形切片感”，但没有把它们冒充 24 张独立绘制人物。
- 音频是项目内原创合成的“现场感近似”，不是实录古乐器采样，也不是参考视频音频复制。最终音色审美仍需用户用实际音箱试听。
- V2 完成短时压力和完整 E2E，尚未在目标投影电脑完成新的 60 分钟或 4–8 小时长稳测试。
- 实体摄像头、投影亮度、现场白平衡、真实多人遮挡和 Homography 仍需在安装现场复验。
