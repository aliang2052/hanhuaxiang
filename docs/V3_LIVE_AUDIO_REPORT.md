# 汉画像·百戏乐舞 V3 Live 音频实现记录

版本：`4.0.0-v3-live`

## 目标

- 63 个画格尽量做到一种声音只使用一次；
- 由程序合成近似音色改为真实演奏录音；
- 保留画面左右定位和多人合奏能力，同时避免重混响、重压缩把音色糊在一起；
- 全部素材可以离线交付并有明确许可。

## 声音来源

- 素材库：Versilian Community Sample Library（VCSL）；
- 创作者：Versilian Studios LLC 与 VCSL 贡献者；
- 许可：CC0 1.0；
- 官方页面：https://versilian-studios.com/vcsl/
- 上游仓库：https://github.com/sgossner/VCSL
- 本项目采用的压缩镜像：https://github.com/danigb/samples/tree/main/audio/vcsl

项目内保存 246 个精选源录音，来自 63 个不同乐器 / 奏法目录。每个文件的上游相对路径、字节数和 SHA-256 均记录在 `assets/audio-source/vcsl/manifest.json`。

## 一格一声架构

- `config/scene.json` 包含 63 个 audioGroup；
- 63 个节点使用 63 个不同 audioGroup，不存在两个格子共享同一条音轨；
- 每条运行时音轨由最多 4 个同乐器真实样本轮替编排，降低机械重复感；
- 画面动作与声音类别对应：弹拨、持续弓奏、吹奏、钟磬、木击、大型鼓乐和舞蹈节奏分别使用不同声音池。

## 现场混音

- 原录音的起音、呼吸、击弦、敲击和房间尾音被保留；
- 总线压缩由 V2 的强压缩改为约 `2.2:1` 轻量保护；
- 厅堂混响时长由 `2.35s` 降为 `1.55s`，返回电平由 `0.32` 降为 `0.14`；
- 多人同时入场时按激活声部数量做能量补偿，避免声部越多越容易削顶；
- 所有音轨仍按人物所在画面位置进行立体声声像定位。

## 事实边界

这些声音来自真实演奏采样，但不是考古复原的汉代出土乐器录音。主音色优先使用筝、诗琴、竖琴、木笛、陶笛、钟锣和世界打击乐；为增加差异度，少量位置使用萨克斯、口琴等现代乐器。参考视频中的音乐没有被提取或复制。

## 验收结果

- 音频专项校验：63 个画格使用 63 个不重复 audioGroup，来自 63 个不同录音目录、246 个源录音；解码后的 63 条运行音轨全部不同；
- 电平检查：所有音轨均为 16.000 秒，无静音、无削波；RMS 为 `0.0279–0.0951`，峰值为 `0.2126–0.9694`；
- 音色差异抽检：63 条音轨的平均两两频谱相似度由 V2 的 `0.807` 降至 `0.446`，1953 对中仅 1 对达到 `0.98`（同一组水晶杯快摩 / 慢摩）；
- 资产冷重建：152 个生成输出完成两次独立重建，OGG 解码 PCM、图像语义和确定性文件均与交付版本一致，验证过程未修改工作树；
- 代码检查：45 个 JavaScript 文件通过语法检查，38 项单元测试、2 项服务器测试全部通过；
- 浏览器 E2E：主流程 36 项、摄像头竞争 10 项、摄像头识别 10 项、断线重连 8 项，共 64 项全部通过；63/63 音轨在 Chrome 中完成加载，无控制台错误、页面错误或外部网络请求。

可重复执行的音频验收命令为 `npm run audio:verify`，完整资产验收命令为 `npm run assets:verify`。
